# 💻 Exercícios: Tipos Primitivos e Variáveis em TypeScript

Este repositório contém a resolução de uma lista de exercícios práticos em TypeScript. O foco destas atividades é fixar o conhecimento sobre declaração de variáveis, tipagem estática, estruturas condicionais e laços de repetição.

## 📌 Instruções Gerais

- Todos os exercícios foram resolvidos em arquivos `.ts`.
- Nos exercícios que pedem para forçar um erro do TypeScript (como atribuição de tipos incorretos), o erro **não foi corrigido**. Em vez disso, o comportamento e a mensagem de erro do compilador foram devidamente documentados em forma de comentário no próprio código.

## 📝 Lista de Exercícios

1. **Tipos Primitivos:** Declare uma variável para cada tipo primitivo básico do TypeScript (`string`, `number`, `boolean`), atribuindo valores de sua escolha.
2. **Erro de Tipagem:** Tente declarar uma variável do tipo `number` e atribuir a ela um valor do tipo `string` (ex: "vinte"). O que o TypeScript acusa? Anote o erro em comentário.
3. **Condicional (Maioridade):** Crie uma variável `idade: number` e escreva uma estrutura condicional (`if/else`) que exiba "Maior de idade" se for maior ou igual a 18, e "Menor de idade" caso contrário.
4. **Condicional (Notas):** Crie uma variável `nota: number` e utilize `if / else if / else` para classificar a nota em "Aprovado" (nota >= 7), "Recuperação" (nota >= 5 e < 7) ou "Reprovado" (nota < 5).
5. **Switch Case (Dias da Semana):** Crie uma variável `diaDaSemana: number` (1 a 7) e utilize um `switch` para exibir o nome do dia correspondente.
6. **Loop For:** Utilize um loop `for` para exibir no console os números de 1 a 10.
7. **Loop While (Pares):** Utilize um loop `while` para exibir apenas os números pares entre 1 e 20.
8. **Loop For...Of (Soma):** Crie um array `numeros: number[]` com pelo menos 5 valores e utilize um loop `for...of` para somar todos os elementos, exibindo o total ao final.
9. **Loop + Condicional (Ímpares):** Utilize um loop `for` combinado com uma condicional para exibir apenas os números ímpares entre 1 e 15.
10. **Desafio Final:** Combine tudo o que foi visto — crie um array de números, percorra com um loop e, para cada número, utilize uma condicional para classificá-lo como "par" ou "ímpar", exibindo o resultado no console.
